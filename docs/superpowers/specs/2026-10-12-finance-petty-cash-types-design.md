## 2. รายละเอียดต่อประเภท

### 2.1 ค่าชั่งน้ำหนัก (`WEIGH`) — ดู `DESIGN-WEIGH.md`

ตัวตั้งต้นของทั้งโมดูล มีเอกสารจริงประกอบครบ (ใบ 1,640 บาท 16 คัน 3 ราคา 17–24/9)
ข้อที่ประเภทอื่นยืมมาใช้: การกรอกเป็นรายการ · ปุ่มเพิ่มหลายคัน · การจัดกลุ่มตอนพิมพ์ตามราคา+ประเภทรถ

### 2.2 ค่าทางด่วน (`TOLL`)

**ต่างจากค่าชั่งน้ำหนักตรงไหน** — มีใบเสร็จจากด่านจริง จึง **ไม่ต้องมีใบรับรองแทนใบเสร็จ**
และปกติเป็นรายการเดียวต่อใบ จึงกรอกแบบยอดเดียว (ระบบสร้างรายการลูก 1 แถวให้เอง)

| ช่องกรอก | บังคับ |
|---|---|
| วันที่ใช้ทาง | ✅ |
| รถ (เลือกจาก master) | ✅ |
| พจส. | ✅ |
| จำนวนเงิน | ✅ |
| เลขที่ใบเสร็จ | — |

**ข้อค้าง** — ใบเสร็จค่าทางด่วนตัวจริงกระดาษเล็กและหายง่าย ถ้าต้องการสถานะติดตามว่า
"บัญชีได้รับตัวจริงแล้วหรือยัง" ต้องเพิ่มช่องใหม่ (ยังไม่ทำ รอคำตอบ)

### 2.3 ค่าปะ-เปลี่ยนยาง (`TIRE`)

**ลักษณะงาน** — ใบเดียวมักมีหลายคัน/หลายเส้น และราคาต่างกันตามงาน จึงกรอกเป็นรายการ

| ช่องกรอกต่อแถว | บังคับ |
|---|---|
| วันที่ | ✅ |
| รถ | ✅ |
| เลขที่ใบเสร็จ/บิล | ✅ |
| รายการที่ทำ (เช่น ปะ 1 เส้น / เปลี่ยน 2 เส้น) | ✅ |
| จำนวนเงิน | ✅ |

รูปยางที่เปลี่ยนเป็นหลักฐาน**ไม่บังคับ** — ต่างจากค่าซ่อมฉุกเฉินที่บังคับ เพราะงานยางมีบิลร้านชัดเจน
ผูกรหัส ATMS `LB00009` ไว้แล้วสำหรับ DD

### 2.4 ค่าซ่อมฉุกเฉิน (`REPAIR`)

**ประเภทที่คุมเข้มที่สุด** เพราะเป็นงานนอกแผนและราคาไม่มีมาตรฐาน

| ช่องกรอกต่อแถว | บังคับ |
|---|---|
| วันที่ซ่อม | ✅ |
| รถ | ✅ |
| เลขที่ใบเสร็จ/ใบแจ้งซ่อม | ✅ |
| อาการ/งานที่ทำ | ✅ |
| จำนวนเงิน | ✅ |

**บังคับรูปหน้างาน** — ข้อนี้ต่างจากทุกประเภท เพราะงานซ่อมฉุกเฉินตรวจย้อนหลังจากเอกสารอย่างเดียวไม่ได้

**ข้อเสนอที่ยังไม่ทำ** — ถ้าใบแจ้งซ่อม (MR) ในระบบ ATMS มีเลขอยู่แล้ว ควรให้กรอกเลข MR
แล้วระบบดึงอาการ/ทะเบียนมาเติมให้ แบบเดียวกับที่ทำกับ DD (ประหยัดการพิมพ์และกันกรอกผิดคัน)

### 2.5 ค่าเดินทางคนขับ (`TRAVEL`)

**ประเภทเดียวที่ไม่ผูกกับรถ** — ผูกกับคนขับ ด่านซ้ำอ่อนจึงเปลี่ยนคีย์เป็น **วันที่ + คนขับ**
ไม่ใช่วันที่ + รถ และมีใบรับรองแทนใบเสร็จ เพราะค่าเดินทาง (รถโดยสาร/วินมอเตอร์ไซค์) มักไม่มีใบเสร็จ

| ช่องกรอก | บังคับ |
|---|---|
| วันที่เดินทาง | ✅ |
| พจส. | ✅ |
| เส้นทาง/เหตุผล | ✅ |
| จำนวนเงิน | ✅ |

**ข้อค้าง** — ยังไม่มีเพดานต่อครั้ง/ต่อเดือน ถ้าต้องการให้เตือนเมื่อเกิน (เช่น เกิน 500/ครั้ง
หรือเกิน 3 ครั้ง/เดือนต่อคน) เพิ่มกฎใน `spec.rules` ได้โดยไม่ต้องแก้โค้ด แต่ต้องบอกตัวเลขมาก่อน

## 4. การเพิ่มประเภทที่ 6 ขึ้นไป

ไม่ต้องแก้โค้ด ทำ 3 ขั้น:

1. เพิ่มแถวใน `fin_petty_expense_types` (รหัส · ชื่อไทย · รหัส ATMS ถ้ามี)
2. วาง `spec` ที่หน้า **ตั้งค่าเงินสดย่อย → ประเภทการเบิก** โดยลอกจากประเภทที่ใกล้ที่สุด
3. ถ้ามีหมวดไฟล์แนบใหม่ (นอกจาก `weigh_slip` `transfer` `receipt` `photo` `id_card` `other`)
   ต้องเพิ่มชื่อหมวดใน `lib/finance/petty-upload.ts` ด้วย — ข้อนี้ข้อเดียวที่แตะโค้ด
   (ตั้งใจให้แตะ เพราะ whitelist คือสิ่งที่กันคนอัปโหลดเข้าโฟลเดอร์อะไรก็ได้)
